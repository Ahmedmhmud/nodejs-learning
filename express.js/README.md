# express.js notes

Express.js is a minimal unopinionated framework for NodeJS, and unopinionated means you can structure your application in any way you want, use any library so there is no a lot of conventions and stricted rules to do it.

Opinionated frameworks are like Laravel, the sturcture is stricted and Laravel itself comes with a lot of bells tools like CLI and ORM and athentication so you can use the recommended way to build your apps, unlike express.js.
